# 🚀 Quickstart: First Session (30 minutes)

Welcome to the three-bot collective system! This guide will get you up and running in 30 minutes.

## 0-5 Minutes: Understand the Basics

### What You Need to Know
- **Three Bots**: Coordinator (organizer), Specialist (expert), Validator (quality checker)
- **Your Role**: Ask questions naturally—the bots handle the complexity
- **How It Works**: Your request flows through all three bots automatically
- **Quality**: Each response is validated before you see it

### Quick Visual
```
You Ask → Coordinator Routes → Specialist Processes → Validator Checks → You Get Answer
```

## 5-10 Minutes: Your First Request

### Try This Simple Task
**Prompt**: *"I need a summary of machine learning basics"*

**What Happens Behind the Scenes**:
1. **Coordinator** recognizes this is an educational request
2. **Specialist** generates comprehensive but accessible summary
3. **Validator** checks accuracy and clarity
4. **You receive** polished, validated response

### What You'll Notice
- Response is thorough but not overwhelming
- Technical accuracy is verified
- Explanation is clear and well-organized
- You can see any confidence notes or limitations

## 10-15 Minutes: Try a Complex Request

### Step Up the Difficulty
**Prompt**: *"How would I compare option A vs option B for my [situation]?"*

**This Tests**:
- ✓ Multi-factor analysis
- ✓ Context understanding
- ✓ Balanced perspective
- ✓ Practical recommendations

**What to Expect**:
- More thorough validation process (takes a few seconds)
- Detailed reasoning shown
- Trade-offs clearly presented
- Uncertainty acknowledged

## 15-20 Minutes: Explore Edge Cases

### Challenge the System
**Try These**:
- Contradictory requirements ("I want X but also Y...")
- Sensitive topics (see what disclaimers appear)
- Technical deep dives (watch specialist expertise shine)
- Creative/analytical mix (see coordination in action)

**Expected Behavior**:
- System handles contradictions gracefully
- Relevant disclaimers automatically included
- Clear escalation for ambiguous cases
- Follow-ups offered when helpful

## 20-25 Minutes: Learn the Features

### Key Commands & Patterns

**For Clarification**:
- "Can you explain that differently?"
- "I didn't understand [part]"
- "What do you mean by [term]?"

**For Refinement**:
- "That's close but focus more on..."
- "Can you make this shorter/longer?"
- "What if we considered [angle]?"

**For Exploration**:
- "What about edge case [X]?"
- "Tell me alternatives"
- "What would an expert in [field] say?"

**For Validation**:
- "Can you fact-check that claim?"
- "Is this safe to do?"
- "What are the risks here?"

### Response Options Available
- Follow-up questions
- Refined versions
- Alternatives
- Deeper dives
- Resource recommendations

## 25-30 Minutes: Best Practices

### Do's ✓
- Be specific about your needs
- Provide context when relevant
- Ask for clarifications
- Request multiple perspectives
- Note what's most helpful

### Don'ts ✗
- Assume you need to be brief
- Skip important details
- Accept answers without pushback
- Treat validators as obstacles
- Expect immediate perfect answers

### Tips for Best Results

**1. Context is Your Friend**
```
Better: "I need Python code to parse JSON with error handling"
Less Effective: "Help with JSON"
```

**2. State Your Goal**
```
Better: "I'm learning data science and need..."
Less Effective: "How do I...?"
```

**3. Clarify What Matters**
```
Better: "Prioritize readability over performance"
Less Effective: "Write some code"
```

**4. Request Validation**
```
Better: "Double-check this for edge cases"
Less Effective: "Is this right?"
```

## Troubleshooting

### "The response seems incomplete"
→ Ask Specialist to expand specific section

### "I'm not sure if this is accurate"
→ Request Validator review explicitly: "Fact-check this"

### "This doesn't match what I need"
→ Provide feedback: "I meant [clarification]"

### "Response took too long"
→ Simpler questions → faster response. Ask for specific instead of broad.

## Common First-Session Questions

**Q: Why does validation add time?**
A: It ensures accuracy and safety. 2-3 seconds is worth reliable answers.

**Q: Can I skip validation?**
A: Safety checks are always on. Other validation can be informally waived.

**Q: What if I disagree with a decision?**
A: Provide feedback. System learns and improves. You can override recommendations.

**Q: How do I know what each bot did?**
A: Reasoning is shown for important decisions. Ask "Why?" for full explanation.

**Q: Can I request specific bot handling?**
A: Yes. "Route to Specialist directly" or "I need Validator review" both work.
