# HOW TO OPEN
### The Book of Secret Knowledge

---

You found the door. Here is how it opens.

## First Threshold — Read It As Written

Open `README.md` on GitHub. This is the book in its native form —
the master document, the spine everything else hangs from.

## Second Threshold — Read It As Bound

Open `book_readme.html`, either on GitHub or downloaded to your own
machine. This is the letter-formatted rendering — the same words,
given a shape meant for reading rather than editing.

```
Download book_readme.html
+ any files it references under assets/
→ open in Chrome, Firefox, Edge, or Safari
```

No server required. No build step. The book opens the way a book
should — you point a browser at it and it's there.

## Third Threshold — Read It As Made

If you want to see how the binding happens, not just hold the
finished object:

- `/chapters` — the modular source, unbound, editable
- `/notes` — session logs, margins, the working scaffolding
- `render_book.py` — the script that turns HTML into PDF

Run it if you have the dependencies. Watching the render is its own
kind of reading.

## If You Want to Add a Page

Fork it. Edit a chapter file. Open a pull request. Use issues to
propose a question worth asking, or a session worth logging.

The book stays open because people keep opening it.
